# 03 Traceability

Build bidirectional traceability from system requirements to subsystem requirements, architecture blocks, implementation modules, tests, and evidence. Identify orphan requirements and unverified design behavior.

## Required response format
1. Inputs/assumptions
2. Work performed
3. Files created/modified
4. Interfaces affected
5. Verification performed
6. Acceptance criteria
7. Risks/TBDs
8. Next dependency
