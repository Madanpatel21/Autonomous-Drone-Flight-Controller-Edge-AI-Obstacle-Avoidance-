# 01 Project Discovery

Define the project scope, users, operating concept, vehicle class, performance targets, constraints, interfaces, safety boundaries, regulatory assumptions, and acceptance criteria. Convert every statement into a uniquely identified requirement or explicit open decision. Do not choose components yet.

## Required response format
1. Inputs/assumptions
2. Work performed
3. Files created/modified
4. Interfaces affected
5. Verification performed
6. Acceptance criteria
7. Risks/TBDs
8. Next dependency
