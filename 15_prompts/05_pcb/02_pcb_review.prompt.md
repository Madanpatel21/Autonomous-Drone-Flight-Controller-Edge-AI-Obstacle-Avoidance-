# 02 Pcb Review

Perform a schematic and PCB design review. Look for power integrity, signal integrity, grounding, thermal, EMI, manufacturability, connector errors, pin swaps, missing pull-ups, inaccessible debug, and sensor-placement problems. Produce actionable findings with severity.

## Required response format
1. Inputs/assumptions
2. Work performed
3. Files created/modified
4. Interfaces affected
5. Verification performed
6. Acceptance criteria
7. Risks/TBDs
8. Next dependency
