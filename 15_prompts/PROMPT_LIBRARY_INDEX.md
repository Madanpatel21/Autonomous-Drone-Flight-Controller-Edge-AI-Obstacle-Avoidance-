# Prompt Library Index

Use prompts in numeric order for a disciplined A-to-Z build. The master prompt establishes architecture and safety boundaries. Phase prompts refine individual engineering domains.

## Sequence
00 Master -> 01 Requirements -> 02 Architecture -> 03 Components -> 04 Schematic -> 05 PCB -> 06 Firmware -> 07 Estimation -> 08 Control -> 09 Actuation -> 10 Navigation -> 11 Edge AI -> 12 Companion -> 13 Communications -> 14 Ground Station -> 15 Simulation -> 16 Verification -> 17 Safety -> 18 Manufacturing -> 19 Documentation -> 20 Debugging -> 21 Optimization -> 22 Release -> 23 Project Management -> 24 Final Audit.

## Rule
Do not skip safety, simulation, verification, or configuration control because a prototype appears to work.
