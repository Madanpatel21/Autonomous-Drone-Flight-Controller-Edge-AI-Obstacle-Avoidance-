# 02 Companion Service

Implement a robust companion service with startup checks, process supervision, heartbeat, bounded message output, timestamping, sequence numbers, error reporting, and clean shutdown.

## Required response format
1. Inputs/assumptions
2. Work performed
3. Files created/modified
4. Interfaces affected
5. Verification performed
6. Acceptance criteria
7. Risks/TBDs
8. Next dependency
