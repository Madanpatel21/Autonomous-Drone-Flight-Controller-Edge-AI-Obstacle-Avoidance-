# 02 Production Test

Create a production test procedure for each manufactured flight-controller board: visual, electrical, programming, rails, communications, sensors, actuator outputs, calibration, logging, and final acceptance.

## Required response format
1. Inputs/assumptions
2. Work performed
3. Files created/modified
4. Interfaces affected
5. Verification performed
6. Acceptance criteria
7. Risks/TBDs
8. Next dependency
