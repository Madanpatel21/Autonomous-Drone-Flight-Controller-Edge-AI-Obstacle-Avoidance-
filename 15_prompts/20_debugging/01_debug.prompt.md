# 01 Debug

When a failure occurs, reproduce it, classify it, collect logs, isolate the fault domain, propose minimal hypotheses, test them, identify root cause, implement the smallest safe fix, add regression coverage, and update traceability.

## Required response format
1. Inputs/assumptions
2. Work performed
3. Files created/modified
4. Interfaces affected
5. Verification performed
6. Acceptance criteria
7. Risks/TBDs
8. Next dependency
