# PHASE 02 — Requirements Engineering

Read `15_prompts/00_AGENT_CONTRACT.md` first.

## Task
Create the authoritative requirements baseline for hardware, firmware, control, sensors, navigation, AI, communications, ground station, simulation, testing, safety, manufacturing and operations. Give every requirement a unique ID, acceptance criterion and verification method. Acceptance: every capability is testable.

## Completion gate
- Verify acceptance.
- Update `00_project_control/PROJECT_STATUS.md`.
- Update affected traceability/decision records.
- Record actual tests and evidence.
- Record blockers honestly.
- Read `15_prompts/INDEX.md` and execute the next incomplete phase automatically.
