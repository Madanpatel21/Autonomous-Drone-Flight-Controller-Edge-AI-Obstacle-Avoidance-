# 01 Protocol

Design the telemetry and companion protocol. Include framing, sequence numbers, timestamps, units, coordinate frames, validity, confidence, CRC/integrity, heartbeat, timeout, versioning, and backward compatibility.

## Required response format
1. Inputs/assumptions
2. Work performed
3. Files created/modified
4. Interfaces affected
5. Verification performed
6. Acceptance criteria
7. Risks/TBDs
8. Next dependency
