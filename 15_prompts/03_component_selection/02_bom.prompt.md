# 02 Bom

Generate an engineering BOM with manufacturer part number, package, quantity, reference, electrical role, source, alternatives, lifecycle status, and design notes. Mark every unverified item as TBD rather than guessing.

## Required response format
1. Inputs/assumptions
2. Work performed
3. Files created/modified
4. Interfaces affected
5. Verification performed
6. Acceptance criteria
7. Risks/TBDs
8. Next dependency
