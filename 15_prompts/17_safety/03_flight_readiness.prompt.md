# 03 Flight Readiness

Conduct a flight-readiness review using requirements, configuration, mechanical, electrical, software, sensor, telemetry, failsafe, test evidence, operational area, emergency procedures, and rollback criteria.

## Required response format
1. Inputs/assumptions
2. Work performed
3. Files created/modified
4. Interfaces affected
5. Verification performed
6. Acceptance criteria
7. Risks/TBDs
8. Next dependency
