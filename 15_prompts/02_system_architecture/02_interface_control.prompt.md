# 02 Interface Control

Create the Interface Control Document for every hardware and software interface. Define physical interface, electrical assumptions, protocol, message schema, units, coordinate frame, timing, heartbeat, timeout, integrity, compatibility, and failure behavior.

## Required response format
1. Inputs/assumptions
2. Work performed
3. Files created/modified
4. Interfaces affected
5. Verification performed
6. Acceptance criteria
7. Risks/TBDs
8. Next dependency
