# Project Baseline

Purpose: establish the authoritative baseline for requirements, interfaces, architecture, safety, verification, and release.

## Baseline Rules
- Every requirement has a unique ID.
- Every interface is versioned.
- Every safety-critical change requires impact analysis.
- Hardware, firmware, AI model, parameters, and test evidence are released as a matched configuration.
- No flight test uses unverified software or hardware.

## Configuration Items
1. Flight-controller PCB revision
2. Firmware revision
3. Parameter set
4. Companion-computer software revision
5. AI model version
6. Ground-station revision
7. Vehicle configuration
8. Test evidence
